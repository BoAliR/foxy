# foxy (فوكسي)

ثعلب يعيش فوق صندوق المحادثة: لوحة حيّة لمراحل المشروع وفريقه، وشريط تقدم. يتابع آخر ما كتبته، وإذا حدت عن المشروع يرجّعك بكلمة. تقرأ `docs/FOXY.json` في مجلد المشروع وتعيد قراءته كل أربع ثوانٍ.

## التثبيت
```bash
claude plugin marketplace add ~/.claude/mods/foxy
claude plugin install foxy@arya-mods --scope user
```

لغير صاحب الجهاز: أرسل له `FOXY-INSTALL.md`؛ يرفقه في محادثة ويكتب «ثبّت فوكسي».

## النشر والتحديث
`./publish.sh` (أو `./publish.sh minor`) يفحص، يرفع رقم النسخة، ويرفع الملفات إلى السيرفر. كل نسخة مثبّتة تفحص السيرفر كل عشر دقايق وتحدّث نفسها ثم تطلب `/reload-plugins`. المجلد اللي فيه `publish.sh` ما يتحدّث من السيرفر.

## الرسائل
تاب «رسائل»: اضغط «افتح غرفة جديدة» فينسخ لك مفتاحها، وطرّشه لربعك؛ هو يلصقه في نفس التاب عنده. اسمك ياخذه من كلود. المفتاح هو السر كله.

## الأوامر
- `/foxy` يفتح اللوحة. `/foxy plain` و`/foxy colour` يبدّلان شكلها، `/foxy bar` يخفي الشريط ويرجّعه.

## الملف
`docs/FOXY.json`: `{ goal, updated, stages: [{ title, items: [{ t, s: done|doing|todo|owner, note?, who?, sub? }] }], side: [...], agents: [{ key, name, cli?, session? }], focus: { t, side } }`

## الجمل الذكية
مرة كل ساعة يقرأ الثعلب عناوين رابط RSS (الافتراضي: الصفحة الأولى في Hacker News) ويطلب من سونيت 5.5 عشر جمل: ثلاث أفكار للمشروع، ثلاث تلميحات عن كلود كود، ثلاثة أخبار، ونكتة. تكلفة الساعة أقل من سنت. يُطفأ من إعدادات الإضافة (خانة «جمل ذكية بسونيت»)، ويُبدّل الرابط والموديل من الخانتين المجاورتين.
